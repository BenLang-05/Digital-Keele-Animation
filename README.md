# Digital Keele Animation
A Processing animation project inspired by the Keele University campus. 
The project combines sprite animation, procedural graphics, and animated visual effects to create a short digital scene featuring squirrels, animated trees, and binary rain.

## Features
Sprite-based squirrel animation,
Animated background movement,
Procedurally generated cherry blossom tree,
Animated branches using Perlin noise,
Binary rain visual effect,
Scrolling credits sequence,
Scene transitions and timed animation

## Technologies Used
Processing (Java)

## Project Overview
This project was developed using Processing and explores a range of animation and graphics programming techniques.
The animation depicts a scene in the Keele University Students' Union square, featuring animated squirrel sprites, a dynamically generated cherry blossom tree, and a binary rain effect inspired by digital-themed visualisations.

The project demonstrates the use of sprite animation, transformations, procedural generation, loops, selection statements, and text rendering within Processing.

## Project Structure
The main Processing sketch contains:

Sprite animation and movement logic,
Tree generation and animation,
Binary rain effects,
Scene management,
Credits system

## Notes
This repository is intended to showcase animation and graphics programming concepts using Processing. 
The project was originally developed as part of a university module and demonstrates the application of procedural graphics, animation techniques, and visual effects.
